# Аналитика (GA4) — инструкция

## Что подключено
На всех страницах (`index.html`, `case-study.html`, `privacy.html`) стоит код Google Analytics 4:
- автоматически считает просмотры страниц, посетителей, источники трафика, устройства/страны, скролл (GA4 сам трекает 90%-скролл, время на странице, клики по внешним ссылкам — "Enhanced measurement");
- дополнительно шлёт свои события:
  - `cta_click` — клики по ключевым кнопкам (Hero "Собрать сайт"/"Рассчитать", карточки тарифов, финальная кнопка);
  - `generate_lead` — отправка контактной формы и всплывающего попапа (конверсии);
  - `lead_popup_shown` — попап показан пользователю.
- Уважает баннер согласия (RODO/GDPR): если пользователь нажал «Отклонить», данные в GA4 не отправляются (Google Consent Mode, `analytics_storage: denied`), включаются только при «Принять всё».

## Шаг 1 — создать GA4-счётчик
1. https://analytics.google.com → админка → **Создать ресурс** (Property) → тип **Веб**.
2. Укажи адрес сайта, часовой пояс, валюту.
3. Скопируй **Measurement ID** — выглядит как `G-XXXXXXXXXX`.

## Шаг 2 — вставить ID
В каждом из 6 файлов (`just-a-website/` и `deploy/`: `index.html`, `case-study.html`, `privacy.html`)
найди в `<head>` строку:
```
var GA_ID = 'G-XXXXXXXXXX';
```
и замени `G-XXXXXXXXXX` на свой реальный ID. Пришли мне ID в чат — я вставлю сама.

## Где смотреть данные
В GA4 (analytics.google.com) — отдельный дашборд не нужен, всё уже есть:
- **Отчёты → Обзор / В реальном времени** — трафик, посетители, источники, устройства;
- **Отчёты → Вовлечённость → События** — `cta_click`, `generate_lead`, `lead_popup_shown` по отдельности;
- в **Администратор → События** отметь `generate_lead` как **конверсию** — тогда она попадёт в основной отчёт по конверсиям.

## Заявки из форм
Сами данные заявок (имя, email, телефон и т.д.) продолжают идти в Google Sheet, как раньше — GA4
считает только сам факт и количество отправок форм, без личных данных.
