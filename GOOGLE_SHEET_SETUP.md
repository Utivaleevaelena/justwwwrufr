# Zbieranie zgłoszeń w Google Sheet — instrukcja / инструкция (меню на English)

Обе формы лендинга (контактная форма + всплывающее окно) пишут заявки
в одну Google-таблицу, присылают письмо Елене и сообщение в WhatsApp.
Ниже все пункты меню — на **английском** (как у тебя в таблице).

---

## Шаг 1 — Лист в таблице
1. Таблица уже создана.
2. Внизу переименуй лист в **`Leads`** (правый клик по вкладке листа → **Rename**).
   Заголовки колонок скрипт создаст сам при первой заявке.

## Шаг 2 — Вставить скрипт
1. В таблице открой меню **Extensions → Apps Script**.
2. Удали весь код в `Code.gs` и вставь целиком содержимое файла
   **`apps-script.gs`** (apikey WhatsApp `2099636` уже внутри).
3. Нажми **Save** (💾) вверху.

## Шаг 3 — Опубликовать как Web App
1. Вверху справа: **Deploy → New deployment**.
2. Слева от «Select type» нажми ⚙️ (шестерёнку) → выбери **Web app**.
3. Настройки:
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
4. Нажми **Deploy**.
5. Появится окно доступа → **Authorize access** → выбери свой аккаунт →
   на экране «Google hasn’t verified this app» нажми **Advanced** →
   **Go to (project name) (unsafe)** → **Allow**.
6. Скопируй **Web app URL** — он заканчивается на `/exec`.

## Шаг 4 — Прислать URL мне
Скинь этот `/exec` URL сюда, в чат — я вставлю его в формы лендинга.
(Можешь и сама: в `JustContact.jsx` заменить `PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL`
на свой URL — одного места хватит, попап берёт тот же URL.)

Проверка, что скрипт живой: открой `/exec`-URL в браузере —
должно показать «OK — Just a Website lead endpoint is live.»

придёт письмо и сообщение в WhatsApp. Нет письма — проверь папку «Спам».

Если меняешь `apps-script.gs`: **Deploy → Manage deployments →
✏️ (Edit) → Version: New version → Deploy**. URL остаётся тем же.

## Примечания
- Форма шлёт данные как `text/plain`, чтобы не было CORS-preflight —
  это нормально, Apps Script читает JSON из тела запроса.
- Поле `Źródło` показывает, откуда заявка: `Just a Website Landing Page`
  (контактная форма) или `Just a Website — Free Mini Consultation` (попап).
